**Ein Studio, das aus einem Song entstanden ist.**

Hookline ist ein Studio im Browser: Instrumental ablegen, Lyrics mit Abschnitts-Tags schreiben, eine Stimme wählen, rendern. Die Stimme entsteht lokal mit ACE-Step auf der eigenen Grafikkarte, Whisper prüft das Ergebnis gegen den Text. Kein Upload, keine Warteschlange, nichts verlässt den Rechner.

**Der erste Song** — CEILING: dunkler Hyperpop mit Breakcore-Anteilen, der Beat prozedural in Python erzeugt, die Lyrics in dreiundzwanzig Versionen, der Master 180 Sekunden in 24 Bit. Daraus wurde erst CEILING Studio, eine einzelne HTML-Datei mit Web Audio, und dann Hookline.

**Stand** — lokale Alpha mit Song-Studio, Create-Flow und Bibliothek. Die Stimme ist eine KI-Stimme, und das steht hier, damit es niemand raten muss. Cover und Wellenform sind aus dem echten Master gerendert.

<div data-lang="en">

**A studio that grew out of a song.**

Hookline is a studio in the browser: drop an instrumental, write lyrics with section tags, pick a voice, render. The vocal is generated locally with ACE-Step on my own graphics card, Whisper checks the result against the text. No upload, no queue, nothing leaves the machine.

**The first song** — CEILING: dark hyperpop with breakcore parts, the beat generated procedurally in Python, the lyrics across twenty-three versions, the master 180 seconds in 24-bit. It became CEILING Studio first, a single HTML file with Web Audio, and then Hookline.

**Status** — local alpha with song studio, create flow and library. The vocal is an AI vocal, and it says so here so nobody has to guess. Cover and waveform are rendered from the real master.
