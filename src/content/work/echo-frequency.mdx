<div data-lang="de">

**Nicht jede Nachricht sagt die Wahrheit.**

Echo Frequency ist ein informationsgetriebenes Mystery-Spiel in Godot 4.7: Du betreibst eine Funkstation auf Blackwater Island und empfängst Nachrichten aus konkurrierenden Realitäten. Deine Entscheidungen verändern, welche Realität überlebt.

**Loop** — Zuhören, abgleichen, festhalten. Frequenzen abstimmen, Sendungen im Notizbuch gegeneinander prüfen, Widersprüche finden. Es gibt kein Rennen, kein Springen, keinen Kampf — das ist Absicht.

**Stand** — v0.17, in Arbeit. Datengetriebene Inhalte, First-Person-3D, Speichern und Laden, Controller-Unterstützung. Der aktuelle Web-Build läuft in der Spielhalle; er zeigt den echten Entwicklungsstand, nicht ein Release.

<div data-lang="en">

**Not every message tells the truth.**

Echo Frequency is an information-driven mystery game in Godot 4.7: you run a radio station on Blackwater Island and receive transmissions from competing realities. Your choices decide which reality survives.

**Loop** — Listen, cross-check, write it down. Tune frequencies, compare broadcasts in the notebook, find the contradictions. There is no sprint, no jump, no combat — by design.

**Status** — v0.17, in progress. Data-driven content, first-person 3D, save and load, controller support. The current web build runs in the arcade; it shows the real development state, not a release.

</div>
