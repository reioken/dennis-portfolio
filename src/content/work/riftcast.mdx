<div data-lang="de">

**Aufgabe** — Den eigenen PC auf Phone und Browser nutzen, ohne dafür einen Cloud-Account anzulegen.

**Mein Beitrag** — Konzept, UX/UI und Entwicklung über drei Oberflächen: Desktop-Host, Phone-App und Browser. Der Host startet die Verbindung; die empfangende Oberfläche bietet Steuerung und Qualitätseinstellungen.

**Gestaltung** — Touch-Bedienung, Gamepad-Layouts und physische Controller erhalten jeweils passende Eingaben. Qualitätspresets machen die Stream-Einstellungen greifbar. Für den optionalen Zugriff über einen privaten Tunnel gibt es einen Session-Code.

**Ergebnis** — Ein privater Build für Phone, Browser und Desktop-Host. Die Galerie lässt zwischen den Oberflächen wechseln und zeigt, wie dieselbe Verbindung je nach Gerät bedient wird.

</div>

<div data-lang="en">

**Brief** — Use your own PC on a phone or in a browser without creating a cloud account.

**My contribution** — Concept, UX/UI and development across three surfaces: desktop host, phone app and browser. The host starts the connection; the receiving interface provides controls and quality settings.

**Design** — Touch controls, gamepad layouts and physical controllers each have appropriate input options. Quality presets make stream settings tangible. Optional access through a private tunnel uses a session code.

**Result** — A private build for phone, browser and desktop host. Switch between the gallery surfaces to see how the same connection is controlled on different devices.
