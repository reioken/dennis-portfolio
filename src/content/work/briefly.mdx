<div data-lang="de">

**Eine Zeitung für genau einen Leser.**

Briefly ist mein Morgen-Briefing: Um 7:00 Uhr recherchiert ein Agent elf Rubriken, die ich selbst festgelegt habe, verdichtet sie zu Stichpunkten und hängt an jede Meldung die Quelle. Dann kommt ein Push. Alles Ältere landet im Archiv.

**Build** — Next.js auf Vercel mit Cron, Postgres für die Ausgaben, Claude für die Recherche, Web Push mit eigenem VAPID-Schlüssel. Der Android-Wrapper ist eine TWA. Gestaltung auf Papierton mit einer System-Serifen, ohne Webfont.

**Stand** — Läuft täglich für eine Person. Nicht öffentlich verlinkt, weil die Rubriken meine sind.

<div data-lang="en">

**A newspaper for exactly one reader.**

Briefly is my morning briefing: at 7:00 an agent researches eleven topics I chose myself, condenses them into bullet points and attaches the source to every story. Then a push. Everything older goes into the archive.

**Build** — Next.js on Vercel with Cron, Postgres for the editions, Claude for the research, Web Push with my own VAPID key. The Android wrapper is a TWA. Set on a paper tone with a system serif, no webfont.

**Status** — Runs daily for one person. Not linked publicly, because the topics are mine.

</div>
