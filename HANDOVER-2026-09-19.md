## 4. Release procedure

```powershell
$env:ASTRO_TELEMETRY_DISABLED='1'
npx tsc --noEmit -p .
npm run test:review
npx astro build            # never `npm run build` or `npm run deploy`: they run the werkstatt scanner / the contact Worker
npm run audit
git status --short src/data   # a changed werkstatt.json must not ship
npx wrangler pages deploy dist --project-name=dennis-portfolio --branch=main --commit-hash=<sha> --commit-dirty=true
```

Commit before the deploy and pass that hash. Then **load the live URL in a headless browser with console
capture and look at a screenshot** (`scripts/qa/live/`), compare a changed asset's SHA-256 with `dist`, update
this handover, commit, push `feat/werkstatt`. Status codes are not verification: a CSP line once blanked the
hall for three deployments while every status was 200.

## 5. Traps (all hit)

- Production-only defects do not reproduce on the dev server (it injects styles early, sends no CSP). Use `astro preview` (launch config `astro-preview`, port 4322) or live.
- `/models/*` and `/textures/*` are edge-cached for a day: changed content needs a new file name or `?v=`. `pack-models.mjs` without `--only` rewrites every GLB; undo with `git checkout -- public/models`.
- Nothing may write inside the project while a browser regression runs against the dev server (Vite reloads the page), not even a markdown file. Probe output goes outside the project.
- Shell heredocs mangle backslashes inside JavaScript; edit JS with an editor tool. A bare `python -` in a command chain hangs on stdin.
- Meshy: the key is `MESHY_API_KEY` in `C:/Users/denni/Projects/survivorlike/.env`; load it into the environment only, never print or store it. 228 credits left on 2026-09-19. Reference images go up as small JPEGs. `OPENAI_API_KEY` is in the shell environment.
- Blender 5.2 resolves relative render paths against `C:\`. Two native sharp builds live in `node_modules`: never import `@gltf-transform/functions` in a process that encodes with sharp.
- `window.__hall` exists on the dev server only. On live, read `performance` marks (`hall:*`) and `data-ready-ms`; screenshot polling slows what it measures.
