## 4. Release procedure

```powershell
$env:ASTRO_TELEMETRY_DISABLED='1'
npx tsc --noEmit -p .
npm run test:review
npx astro build            # never `npm run build` or `npm run deploy`: they run the werkstatt scanner / the contact Worker
npm run audit
git status --short src/data   # a changed werkstatt.json must not ship
npx wrangler pages deploy dist --project-name=dennis-portfolio --branch=main --commit-hash=<sha> --commit-dirty=true
```

Commit before the deploy and pass that hash. Then **load the live URL in a headless browser with console
capture and look at a screenshot** (`scripts/qa/live/`), compare a changed asset's SHA-256 with `dist`, update
this handover, commit, push `feat/werkstatt`. Status codes are not verification: a CSP line once blanked the
hall for three deployments while every status was 200.
