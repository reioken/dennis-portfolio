## 4. How the machines are built (short; the record is docs/hero-machines.md)

```
scripts/models/hero-recipes/<name>.json            the recipe (14 stations + claw-v2)
sh scripts/models/build-hero.sh <name>             bake → attach masks → optimize → pack → prints sha8   (about 5 min, GPU)
src/components/hall/hallScene.ts                   put ?v=<sha8> into MODELS_BY_SLUG / CLAW_MODEL / TV_RIG_MODEL / MODELS.phone
src/components/hall/heroMaterial.ts                surfaces, wear detail, HeroLook, bevel normal, room reflection
```

A GLB carries two UV sets (tiling scans on the first, a visibility-weighted atlas on the second) and up to three
baked atlas textures: mask RGBA (AO, screen light, brand light, wear zones), key-light shadow, bevel normal. The
wear LOOK of a machine is not in the GLB: it is `hero: { seed, lines, chips, turn, scale, chip, line }` next to its
URL in `hallScene.ts`. Control mesh names are the hall's contract; the close-up (`Closeup.tsx`, CRLF) lays invisible
proxies over their projected rectangles.

Things that cost me hours:

- `/models/*` and `/textures/*` are edge-cached for a day. A rebuilt file without a new `?v=` or name shows the OLD
  model on the preview and you will debug the wrong thing. `node scripts/qa/hero/verify-hashes.mjs` checks them all.
- Never set `position` or `scale` on a GLB node at runtime: quantized nodes carry their dequantization there (the claw
  became 50 times too large). Use a holder group or multiply. Multi-material parts arrive as Groups: find them with
  `getObjectByName`, not by walking meshes.
- Never edit TypeScript from a shell (`sed`, heredoc, `node -e`): the `\n` escapes inside the GLSL strings in
  `heroMaterial.ts` turn into real newlines and the shader fails with an unrelated message. Use an editor tool.
- `python -` and Blender hang on stdin in a command chain: append `</dev/null`. Blender needs absolute paths.
- Lossy WebP bleeds between packed channels. The key-light shadow travels as its own grey PNG for that reason.
- Editing anything inside the project, docs included, reloads the dev server page under a running capture.
- `pack-models.mjs` without `--only` rewrites every GLB. `optimize.mjs` needs `--keep-attributes` so the second UV set
  (the atlas all bakes ride on) survives.
