# Afterimage — generated screen mockups

15 selected image boards covering the public site screens, principal UI states, mobile layouts, and cabinet construction.

These are generated images, not code mockups. The full arcade hall remains the design foundation. No site code or 3D assets were changed for this set.

The selected versions below include the corrected desktop button icons and removal of unwanted copy from the project and mobile boards. Earlier unselected drafts remain in this folder for traceability.

[Design constraints and cabinet plan](C:/Users/denni/Projects/dennis-portfolio/design-mockups/afterimage-images/DESIGN-NOTES.md) · [Original generation prompts](C:/Users/denni/Projects/dennis-portfolio/design-mockups/afterimage-images/prompts.json) · [Correction prompts](C:/Users/denni/Projects/dennis-portfolio/design-mockups/afterimage-images/revision-prompts.json)

Generated with the built-in image-generation tool, using the approved first direction, the existing Echo Frequency radio screenshot and Dennis's existing portrait as references. Imagery is illustrative; use the actual project captures, text and action mappings when implementing. Placeholder lines on About/legal screens represent existing content, not a new loading requirement.
